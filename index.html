Bienvenido a la Calculadora de Análisis Numérico

Esta herramienta interactiva ha sido diseñada para facilitar el aprendizaje y la aplicación de métodos numéricos fundamentales. La calculadora permite realizar iteraciones de punto fijo, interpolación de Lagrange e integración numérica mediante reglas del trapecio y Simpson, todo con visualización gráfica en tiempo real y validaciones explicativas detalladas.

Cada módulo incluye representaciones matemáticas profesionales renderizadas con MathJax, gráficos interactivos generados con Chart.js, y un sistema de historial que permite guardar y recuperar ejercicios anteriores. La interfaz es responsiva y se adapta a diferentes dispositivos y orientaciones.

Fórmulas Matemáticas

Referencia de todas las fórmulas utilizadas en la aplicación

Iteración de Punto Fijo

Fórmula Principal

$$x_{n+1} = g(x_n)$$

Método de iteración simple para encontrar raíces de ecuaciones transformadas a la forma x = g(x).

Variables:
  • xn: Valor actual de la iteración (aproximación actual)
  • xn+1: Siguiente valor de la iteración (nueva aproximación)
  • g(x): Función de iteración derivada de la ecuación original
Uso:

Se utiliza para encontrar raíces de ecuaciones cuando se puede transformar f(x) = 0 a x = g(x). El método converge si |g'(x)| < 1 en el intervalo de interés.

Error Aproximado

$$|x_{n+1} - x_n| < \varepsilon$$

Criterio de convergencia basado en la tolerancia especificada.

Variables:
  • xn+1: Valor actual de la iteración
  • xn: Valor anterior de la iteración
  • |…|: Valor absoluto de la diferencia
  • ε: Tolerancia (error máximo permitido)
Uso:

Se detiene el proceso iterativo cuando la diferencia entre iteraciones consecutivas es menor que la tolerancia especificada, indicando que se ha alcanzado la precisión deseada.

Interpolación de Lagrange

Polinomio de Lagrange

$$P(x) = \sum_{i=0}^{n} y_i L_i(x)$$

Polinomio que pasa exactamente por n+1 puntos dados (xi, yi).

Variables:
  • P(x): Polinomio de interpolación resultante
  • n: Grado del polinomio (número de puntos - 1)
  • (xi, yi): Puntos de interpolación dados
  • Li(x): Polinomio base de Lagrange i-ésimo
  • ∑: Sumatoria de i=0 hasta n
Uso:

Se utiliza para encontrar un polinomio que pase exactamente por un conjunto de puntos dados. Es útil para aproximar funciones en puntos intermedios donde no se conocen los valores exactos.

Polinomio Base de Lagrange

$$L_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}$$

Cada polinomio base es 1 en xi y 0 en los otros nodos.

Variables:
  • Li(x): Polinomio base i-ésimo
  • ∏: Productoria (multiplicación de términos)
  • xi: Coordenada x del punto i-ésimo
  • xj: Coordenada x de los otros puntos
  • j ≠ i: Excluye el término cuando j es igual a i
Uso:

Cada polinomio base Li(x) toma el valor 1 en xi y 0 en todos los otros nodos xj. Esta propiedad permite construir el polinomio final como combinación lineal de los polinomios base.

Integración Numérica

Regla del Trapecio (Simple)

$$\int_a^b f(x) dx \approx \frac{b-a}{2} [f(a) + f(b)]$$

Aproximación del área bajo la curva usando un solo trapecio.

Variables:
  • ∫: Integral definida (área bajo la curva)
  • a, b: Límites inferior y superior de integración
  • f(x): Función a integrar
  • dx: Diferencial de x
  • ≈: Aproximación (no es exacto)
Uso:

Método básico que aproxima el área bajo la curva como un trapecio. Es preciso para funciones aproximadamente lineales pero pierde precisión en funciones con alta curvatura.

Regla del Trapecio (Múltiple)

$$\int_a^b f(x) dx \approx \frac{h}{2} [f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n)]$$

Aproximación usando múltiples trapecios. Donde $h = \frac{b-a}{n}$ y $x_i = a + ih$.

Variables:
  • h: Ancho de cada subintervalo (paso)
  • n: Número de subintervalos
  • xi: Puntos de partición (x0 = a, xn = b)
  • f(xi): Valor de la función en cada punto
  • 2: Peso de los puntos interiores
Uso:

Versión mejorada que divide el intervalo en n subintervalos. Aumenta la precisión al usar más trapecios. Funciona con cualquier valor de n (par o impar).

Regla de Simpson 1/3

$$\int_a^b f(x) dx \approx \frac{h}{3} [f(x_0) + 4\sum_{i=1,3,5}^{n-1} f(x_i) + 2\sum_{i=2,4,6}^{n-2} f(x_i) + f(x_n)]$$

Aproximación usando parábolas. Requiere que n sea par.

Variables:
  • h: Ancho de cada subintervalo
  • n: Número de subintervalos (debe ser par)
  • 4: Peso de los índices impares
  • 2: Peso de los índices pares (excepto extremos)
  • 1: Peso de los extremos
Uso:

Método más preciso que el trapecio que usa parábolas para aproximar. Requiere n par porque agrupa subintervalos en pares para ajustar una parábola a cada grupo de tres puntos consecutivos.

Regla de Simpson 3/8

$$\int_a^b f(x) dx \approx \frac{3h}{8} [f(x_0) + 3\sum_{i \neq 0,n, i \not\equiv 0 \pmod{3}} f(x_i) + 2\sum_{i \equiv 0 \pmod{3}, i \neq 0,n} f(x_i) + f(x_n)]$$

Aproximación usando polinomios cúbicos. Requiere que n sea múltiplo de 3.

Variables:
  • 3h/8: Factor de ponderación del método
  • n: Número de subintervalos (debe ser múltiplo de 3)
  • 3: Peso de los puntos no múltiplos de 3
  • 2: Peso de los puntos múltiplos de 3 (excepto extremos)
  • 1: Peso de los extremos
Uso:

Método que usa polinomios cúbicos (grado 3) para aproximación. Requiere n múltiplo de 3 porque agrupa subintervalos en grupos de 3 para ajustar un polinomio cúbico a cada grupo de cuatro puntos consecutivos.
